# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

I recommend **AWS** because it offers many cloud services that can help a startup begin with a small budget and scale as the company grows. The startup can increase its resources when more users start using the mobile application. AWS also provides many services that can help developers build and manage the application. Some useful services are **Amazon EC2, Amazon S3, and Amazon RDS**.

---

## Client B – University

### Recommended Platform: Microsoft Azure

I recommend **Microsoft Azure** because the university already uses Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. Azure provides good integration with these existing systems, which can make the migration easier. The university can also manage its users and cloud resources using Microsoft's identity and management tools. Some useful services are **Azure Virtual Machines, Microsoft Entra ID, and Azure SQL Database**.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

I recommend **Google Cloud Platform (GCP)** because Google provides strong tools for Artificial Intelligence and Machine Learning. GCP also offers high-performance computing resources that can be used for training and running AI models. The company can use Google's AI and data services to develop and manage its research projects. Some useful services are **Compute Engine, Vertex AI, and Cloud Storage**.

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

I recommend **AWS** because it has a large global infrastructure that can support an e-commerce company serving customers around the world. AWS provides services that can automatically scale resources when website traffic increases, which is important for an online shopping platform. It also provides tools for building highly available applications across different regions and Availability Zones. Some useful services are **Amazon EC2, Amazon S3, and Elastic Load Balancing**.
