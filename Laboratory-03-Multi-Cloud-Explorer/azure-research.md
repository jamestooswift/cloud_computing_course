# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. I learned that Azure provides different services that allow users and businesses to run applications, store data, manage databases, and use cloud resources through the internet.

## 2. Global Infrastructure

Azure has data centers in different parts of the world. These are organized into **Regions** and **Availability Zones**. I learned that Azure Regions are geographic locations where Microsoft provides cloud services. Availability Zones help keep applications running even when there is a problem with one location.

## 3. Cloud Management Console

The **Azure Portal** is the website where I can manage Azure services. I can use it to create and manage virtual machines, databases, storage, networking, and other cloud resources.

## 4. Four (4) Core Services

### Azure Virtual Machines

Azure Virtual Machines allow me to create virtual computers in the cloud. I can use them to run applications, websites, and other software.

### Azure Blob Storage

Azure Blob Storage is a storage service that I can use to store files, images, videos, backups, and other types of data.

### Azure SQL Database

Azure SQL Database is a managed database service from Microsoft. It allows applications to store and manage structured data without having to manage the database server manually.

### Azure Virtual Network

Azure Virtual Network allows me to create a private network for my Azure resources. It helps control how virtual machines and other services communicate with each other.

## 5. Three (3) Advantages

### 1. Microsoft Integration

I learned that Azure works well with other Microsoft products and services. This makes it useful for businesses that already use Microsoft technologies.

### 2. Scalability

Azure allows me to increase or decrease resources depending on the needs of an application. This helps businesses handle changes in their workload.

### 3. Wide Range of Services

Azure provides many services for computing, storage, databases, networking, security, artificial intelligence, and other technologies.

## 6. Typical Enterprise Use Cases

I learned that businesses commonly use Azure for:

* Hosting websites and applications
* Storing and backing up company data
* Managing business databases
* Running virtual machines
* Developing and testing applications
* Data analysis and artificial intelligence
* Supporting business applications and services

Overall, I learned that Microsoft Azure is useful for businesses because it provides many cloud services and works well with Microsoft technologies.
