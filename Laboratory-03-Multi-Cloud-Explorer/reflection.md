# Mission Reflection

After completing this cloud computing mission, the cloud platform that impressed me the most was **Amazon Web Services (AWS)**. I was impressed by the large number of services available and how AWS can be used for different types of projects. I also found it useful that AWS provides services for computing, storage, databases, networking, and other technologies in one platform.

I learned that **AWS, Microsoft Azure, and Google Cloud Platform (GCP)** have many similarities. All three provide cloud services that allow users to run virtual machines, store data, manage databases, create networks, and manage user access. They also provide global infrastructure and allow businesses to scale their resources depending on their needs. Even though their services have different names, they provide similar solutions for many common cloud computing requirements.

I also learned that **business requirements are important when choosing a cloud platform**. A company should consider its budget, existing technologies, location of its customers, performance requirements, and the type of application it needs to run. For example, Azure can be a good choice for a company that already uses Microsoft technologies, while GCP can be a strong choice for AI and machine learning projects.

Acting as a **Cloud Solutions Consultant** helped me understand that choosing a cloud platform is not only about choosing the most popular provider. I need to understand the client's actual needs and then recommend the platform and services that best fit those needs.

Finally, this mission improved my **GitHub Cloud Computing Portfolio** because I was able to organize my research, comparisons, recommendations, service references, and Linux investigation in one repository. I also learned how to document my work using Markdown and include screenshots as proof of my activities. Overall, this mission gave me a better understanding of how cloud platforms are used in real-world situations.
