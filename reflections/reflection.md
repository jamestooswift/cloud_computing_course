# Cloud Computing and Version Control Reflection

As an IT student, technology is a major part of my daily life. I use many applications on my phone and laptop every day, but I used to take them for granted. Studying cloud computing has helped me understand how these digital tools actually deliver their services over the internet.

In my routine, I rely heavily on three main cloud applications: Google Drive, Netflix, and Canva. I use Google Drive to store my school projects and documents. I use Netflix to stream movies during my free time. Lastly, I use Canva to design presentations and posters for my subjects.

All three of these applications use the Software as a Service (SaaS) model. This means I can access them directly through a web browser or a mobile app. I do not need to install complicated software files, write code, or manage servers. The service providers handle all the system updates, security, and technical maintenance for me. Regarding deployment, all three run on a Public Cloud. The infrastructure is managed by cloud providers, and services are delivered to millions of users over the public internet.

In addition to using cloud applications, I am also learning how developers build and manage cloud systems using version control tools like Git and GitHub. Version control is very important when working with cloud infrastructure because cloud setups rely heavily on configuration files written as code. If someone makes a small error in the code, it can cause an entire website or cloud service to break.

Git and GitHub help developers track every single change made to project files over time. If something goes wrong, we can easily check who made the edit and quickly revert back to a working version. GitHub also allows team members to work together on the same project without deleting or overwriting each other's work. Overall, using Git keeps our projects safe, organized, and reliable.
